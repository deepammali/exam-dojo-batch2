**Objective:** Answer the Mandatory Access Control questions correctly within the time limit.

1. Run `/challenge/run`. It prints the security levels (highest first) and the categories of a Bell-LaPadula system, then asks 20 questions.
2. Each question asks whether a subject with a given level and categories may **read** or **write** an object with a given level and categories. Answer `yes` or `no`.
3. You have **360 seconds** to answer all 20 correctly. One wrong answer ends the attempt.
